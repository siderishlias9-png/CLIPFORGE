CLIPFORGE AI — FREE BUILD WITH AUTO TITLES

This version removes the Vizard API dependency. It uses faster-whisper for open-source speech transcription, FFmpeg for video processing, and Streamlit for the interface.

NEW: Each generated clip receives a suggested title based on its transcript. You can edit the title in the results panel; the edited title is used as the downloaded MP4 filename.

SETUP ON STREAMLIT COMMUNITY CLOUD
1. Replace app.py, requirements.txt, and packages.txt in the root of your GitHub repository.
2. Commit changes and wait for Streamlit Cloud to redeploy.
3. No API key or Vizard account is needed.

INPUT LIMITATIONS
- Upload MP4/MOV/MKV/WebM, or use a direct public video-file URL.
- YouTube/Twitch watch-page URLs are not scraped or downloaded.
- Videos requiring login, payment, cookies, or access circumvention are not supported.
- Free hosting has CPU, memory, and execution limits. Try shorter videos and the Tiny model first.
- Suggested titles are transcript-based, not generated by a paid LLM, so review them before posting.
- Only process videos you have permission to use.
